## InspireFace SDK 升级 1.1.13 → 1.2.4.post1

- 来源：GitHub `HyperInspire/inspireface-android-sdk` tag `v1.2.4.post1`（native 1.2.4，C API Level 2），经代理 127.0.0.1:7897 下载 tar 包（约 111MB，需后台下载）。
- 替换内容：`inspireface/libs/{arm64-v8a,armeabi-v7a,x86_64}/libInspireFace.so`（新增 x86_64）、`src/main/java` 全量 Java 源码（新增 jni/Native 全量接口、FaceCapture、FaceDetectionSnapshot、NativeConversions 等 16 个类）、模型 `Pikachu`(t4.0)、`version.txt`、`consumer-rules.pro`（JNI 类保留）、`inspireface/sdk/1.2.4/`（C 头文件+API manifest）、`kun.jpg`（仪器化测试用）。

- 构建配置：`inspireface` 与 `app` 的 minSdk 22 → **24**（1.2.4 native 强制要求）；`abiFilters` 加 `x86_64`；模块 version 改为 `1.2.4.post1`；`libs.versions.toml` inspirefaceAndroidSdk 改为 1.2.4.post1。
